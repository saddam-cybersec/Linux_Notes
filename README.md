# Linux Notes

## Basic Commands
- `ls` : List directory contents
- `cd` : Change directory
- `chmod` : Change file permissions
- `cat` : View file content

## File Permissions
- `r` : Read
- `w` : Write
- `x` : Execute

## Security Tips
- Use `sudo` carefully
- Monitor log files in `/var/log/`
- Check running processes with `ps aux`
